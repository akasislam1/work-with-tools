First-time setup (only once)

Your username, password and GitHub access are stored privately in Vercel, never in this page.

  1. Create a GitHub token at github.com/settings/personal-access-tokens/new. Choose Only select repositories (this site's repo) and set Contents to Read and write.
  2. In Vercel open your project → Settings → Environment Variables and add:
    • ADMIN_USERNAME : the username you want
    • ADMIN_PASSWORD : a long password (at least 10 characters, longer is better)
    • GITHUB_TOKEN : the token from step 1
    • GITHUB_REPO : your-username/your-repo
  3. Go to Deployments and redeploy, then sign in here.
